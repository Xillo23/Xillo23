### Featured Project — [Cuphead Online Co-op](https://github.com/Xillo23/CupheadOnlineCoop)

[![Latest Release](https://img.shields.io/github/v/release/Xillo23/CupheadOnlineCoop?style=flat-square&label=release&labelColor=111113&color=e10600)](https://github.com/Xillo23/CupheadOnlineCoop/releases/latest)
[![GitHub Downloads](https://img.shields.io/github/downloads/Xillo23/CupheadOnlineCoop/total?style=flat-square&label=GitHub%20downloads&labelColor=111113&color=242428)](https://github.com/Xillo23/CupheadOnlineCoop/releases)
[![Stars](https://img.shields.io/github/stars/Xillo23/CupheadOnlineCoop?style=flat-square&labelColor=111113&color=242428)](https://github.com/Xillo23/CupheadOnlineCoop/stargazers)
[![Nexus Mods](https://img.shields.io/badge/Nexus%20Mods-%23225-e10600?style=flat-square&labelColor=111113)](https://www.nexusmods.com/cuphead/mods/225)
[![License: MIT](https://img.shields.io/badge/license-MIT-242428?style=flat-square&labelColor=111113)](https://github.com/Xillo23/CupheadOnlineCoop/blob/main/LICENSE)

Play Cuphead's real 2-player co-op online with a friend on another PC — **full native resolution and frame rate on both screens**, with no video stream in between.

- **Native UI in 12 languages:** built from the game's own menus, fonts, and sounds
- **Easy hosting & joining:** automatic **UPnP** port opening, LAN/VPN auto-discovery, **Copy / Paste IP** (`C` / `Ctrl+V`), and a host **Accept / Decline** popup
- **Self-correcting sync & save safety:** silent desync recovery with automatic scene resync if needed; progress is written only to the host's save slot
- **One-click installer** (plus clean Uninstall and manual install option)
