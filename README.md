### ⭐ Featured Project — [Cuphead Online Co-op](https://github.com/Xillo23/CupheadOnlineCoop)

[![Latest Release](https://img.shields.io/github/v/release/Xillo23/CupheadOnlineCoop?style=flat-square&label=release&color=2ea44f)](https://github.com/Xillo23/CupheadOnlineCoop/releases/latest)
[![GitHub Downloads](https://img.shields.io/github/downloads/Xillo23/CupheadOnlineCoop/total?style=flat-square&label=GitHub%20downloads&color=1f6feb)](https://github.com/Xillo23/CupheadOnlineCoop/releases)
[![Stars](https://img.shields.io/github/stars/Xillo23/CupheadOnlineCoop?style=flat-square&color=e3b341)](https://github.com/Xillo23/CupheadOnlineCoop/stargazers)
[![Nexus Mods](https://img.shields.io/badge/Nexus%20Mods-%23225-da8e35?style=flat-square)](https://www.nexusmods.com/cuphead/mods/225)
[![License: MIT](https://img.shields.io/badge/license-MIT-6e7681?style=flat-square)](https://github.com/Xillo23/CupheadOnlineCoop/blob/main/LICENSE)

Play Cuphead's real 2-player co-op online with a friend on another PC — **full native resolution and frame rate on both screens**, with no video stream in between.

- **Seamless native UI:** built from the game's own menus, fonts, and sounds in **12 languages**
- **Easy hosting & joining:** automatic **UPnP** port opening, LAN/VPN auto-discovery, **Copy / Paste IP** (`C` / `Ctrl+V`), and a host **Accept / Decline** popup
- **Self-correcting sync & save safety:** silent desync recovery with automatic scene resync if needed, and progress is written only to the host's save slot
- **One-click installer** (plus clean Uninstall and manual install option)
